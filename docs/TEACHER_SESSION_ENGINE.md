# TeacherSessionEngine Specification (محرك دورة المعلم)
## State Machine & Pedagogical Interaction Lifecycle

---

### 1. The Core Pedagogical Loop (دورة المعلم التفاعلية)

```
                     +---------------------------------------+
                     |                 IDLE                  |
                     +-------------------+-------------------+
                                         | START_SESSION
                                         v
                     +---------------------------------------+
  +----------------->|                LISTEN                 |<--------------------+
  |                  +-------------------+-------------------+                     |
  |                                      | AUDIO_FRAME_RECEIVED                    |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                 ALIGN                 |                     |
  |                  +-------------------+-------------------+                     |
  |                                      | WORDS_ALIGNED                           |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                ANALYZE                |                     |
  |                  +-------------------+-------------------+                     |
  |                                      | METRICS_COMPUTED                        |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                DECIDE                 |                     |
  |                  +-------------------+-------------------+                     |
  |                                      |                                         |
  |       [No Error / Minor Deviation]   |   [Confirmed Error: High Confidence]    |
  |                                      |                                         |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |          INTERRUPT_IF_NEEDED          |                     |
  |                  +-------------------+-------------------+                     |
  |                                      | INTERRUPT_TRIGGERED                     |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                CORRECT                |                     |
  |                  +-------------------+-------------------+                     |
  |                                      | CORRECTION_EXPLAINED                    |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                REPEAT                 |                     |
  |                  +-------------------+-------------------+                     |
  |                                      | REPETITION_HEARD                        |
  |                                      v                                         |
  |                  +---------------------------------------+                     |
  |                  |                CONFIRM                |                     |
  |                  +-------------------+-------------------+                     |
  |                                      |                                         |
  |       [Still Incorrect]              | [Rectified / Passed]                    |
  +--------------------------------------+                                         |
                                         v                                         |
                     +---------------------------------------+                     |
                     |               CONTINUE                |---------------------+
                     +-------------------+-------------------+
                                         | END_SESSION
                                         v
                     +---------------------------------------+
                     |            RECORD_PROGRESS            |
                     +-------------------+-------------------+
                                         |
                                         v
                                    [COMPLETED]
```

---

### 2. State Definitions & Responsibilities

| State | Responsibility | Trigger for Next State |
| :--- | :--- | :--- |
| **LISTEN** | استقبال دفق الصوت اللحظي من الطالب ومراقبة مستويات الطاقة ومؤشرات السكوت. | استلام شريحة صوتية صالحة التحليل (`AUDIO_FRAME_RECEIVED`). |
| **ALIGN** | محاذاة الفونيمات والكلمات المسموعة مع الموضع القرآني المتوقع بدقة. | اكتمال مصفوفة المحاذاة الزمنية (`WORDS_ALIGNED`). |
| **ANALYZE** | تطبيق الفحص الحتمي للحركات، الحروف، وأحكام التجويد وحساب درجات الثقة. | صدور تقرير الفحص الأولي (`METRICS_COMPUTED`). |
| **DECIDE** | تقييم الموقف بموجب مصفوفة الثقة (High/Medium/Low/Unknown) وتحديد ما إذا كان يلزم التدخل. | اتخاذ قرار بالاستمرار، أو طلب الإعادة، أو المقاطعة للتصحيح. |
| **INTERRUPT_IF_NEEDED** | إيقاف التلاوة بلطف ودون فزع في اللحظة المناسبة لتفادي استرسال الطالب في اللحن. | إصدار إشارة الإيقاف الصوتي والبصري (`INTERRUPT_TRIGGERED`). |
| **CORRECT** | عرض موضع الخطأ، وتقديم التوضيح اللفظي والبصري للحكم أو الحرف الصحيح. | استيعاب الطالب للتوجيه (`CORRECTION_EXPLAINED`). |
| **REPEAT** | فتح الميكروفون مجددًا للطالب لإعادة الكلمة أو المقطع المستهدف. | التقاط محاولة الإعادة (`REPETITION_HEARD`). |
| **CONFIRM** | فحص محاولة الإعادة؛ فإن أصاب أثنى عليه وأجازه، وإن أخطأ وجّهه مجددًا بحلم. | تقييم نتيجة الإعادة (`CONFIRMATION_EVALUATED`). |
| **CONTINUE** | إتاحة استئناف التلاوة من الكلمة التالية أو من رأس الآية. | متابعة القراءة رجوعًا إلى `LISTEN`. |
| **RECORD_PROGRESS** | حفظ إحصاءات الجلسة، الأخطاء المصوبة، نسب الإتقان، وتحديث ملف الطالب. | انتقال الجلسة إلى حالة الحفظ النهائي. |
