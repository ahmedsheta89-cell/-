# Recitation Engine Architecture Document (Phase 3)
## نظام محاذاة التلاوة ورصد الأخطاء — معلّم القرآن الرقمي

### 1. ملخص المعمارية (Architecture Overview)
يعتمد نظام الاستماع القرآني على مسار تدفق متسلسل صارم يفصل بدقة بين **الملاحظة الفيزيائية والصوتية** وبين **الحكم التجويدي والشرعي**.

```
[ميكروفون / جهاز التسجيل]
       │ (PCM 16kHz, Web Audio API / In-Memory Streams)
       ▼
[IAudioQualityAnalyzer] ──(غير صالح/تشويش شديد)──► [إيقاف مؤقت وتنبيه الطالب]
       │ (صالح للتحليل)
       ▼
[IVoiceActivityDetector (VAD)] (كشف بداية ونهاية الكلام والفواصل)
       │ (مقاطع الكلام المصنفة)
       ▼
[IRecitationAligner (Forced Alignment)] (محاذاة زمنية مقيدة بنص الآيات الموثقة)
       │ (نتائج المحاذاة الزمنية للكلمات والحروف)
       ▼
[IRecitationErrorDetector] (رصد الانحرافات اللغوية: حذف، إبدال، زيادة، وقوف)
       │ (RecitationObservation فقط — دون أحكام شرعية)
       ▼
[IReligiousErrorClassifier] (تقييم الأحكام: لحن جلي، لحن خفي، أحكام التجويد الموثقة)
       │ (ReligiousErrorClassification)
       ▼
[IConfidenceCalibrationService] (معايرة الثقة متعددة العوامل والأدلة Versioned)
       │ (HIGH, MEDIUM, LOW, UNKNOWN)
       ▼
[IRecitationInterruptionPolicy] (سياسة المقاطعة البيداغوجية والتربوية)
       │ (مقاطعة فورية / إرجاء لرأس الآية / تجاهل عند الشك)
       ▼
[ITeacherSessionEngine] (إرشاد المعلم الرقمي الصوتي والبصري اللطيف)
```

---

### 2. حدود المسؤولية وفصل الطبقات (Strict Separation of Concerns)
1. **الطبقة الصوتية واللغوية (Audio Observation Layer)**:
   - مسؤولة حصراً عن قياس الترددات، الطاقة (RMS)، زمن البدء والانتهاء، ونسب الانحراف الصوتي.
   - **ممنوع قطعي**: لا يجوز لهذه الطبقة إصدار حكم شرعي أو إطلاق مسمى (لحن جلي أو خفي) بمفردها.
2. **الطبقة الشرعية والتجويدية (Religious Evaluation Layer)**:
   - تستقبل الملاحظة الصوتية وتقارنها بالنص القرآني الموثق وقواعد التجويد الحتمية `DeterministicTajweedRuleEngine`.
   - هي الجهة الوحيدة المخولة بتصنيف نوع الخطأ ومستوى الحرمة أو الإخلال.
3. **طبقة المعايرة البيداغوجية (Pedagogical Interruption Layer)**:
   - توازن بين دقة التنبيه وبين الحفاظ على خشوع الطالب واسترساله في التسميع، مانعةً المقاطعة العشوائية أو التخطئة المبنية على احتمالات ضعيفة.

---

### 3. سياسة الخصوصية وأمان التسجيلات (Privacy-First Audio Policy)
- **لا تسجيل دائم بدون موافقة صريحة**: يتم معالجة الصوت في ذاكرة المتصفح المؤقتة (Ephemeral In-Memory Buffers).
- **حسابات محلية (Edge Processing)**: تجري عمليات VAD والمحاذاة الحتمية داخل جهاز المستخدم محلياً.
- **التخلص التلقائي**: تُمسح مصفوفات الـ PCM فور استخلاص الفواصل الزمنية وإكمال المحاذاة.

---

### 4. مستهدفات الأداء وزمن الاستجابة (Latency Benchmarks)
- بدء تشغيل الميكروفون: < 300ms
- زمن معالجة المقطع الصوتي (VAD Frame): < 15ms
- زمن المحاذاة الحتمية لكل كلمة: < 30ms
- معامل الزمن الفعلي (Real-Time Factor - RTF): < 0.20 (أي معالجة ثانية الصوت في أقل من 200ms)
